# Images Directory

This directory contains the images and documents used in the portfolio website.

## Files:

### `header.jpg`
- **Purpose**: Background image for the hero section
- **Recommended size**: 1920x1080px or larger
- **Format**: JPG, PNG, or WebP
- **Current**: Placeholder image (replace with your own)

### `cv.pdf`
- **Purpose**: Your CV/Resume file for download
- **Format**: PDF
- **Current**: Sample PDF (replace with your actual CV)

## How to Update:

1. **Replace header.jpg**: Add your own hero background image
2. **Replace cv.pdf**: Upload your actual CV/resume
3. **Update download filename**: Edit the `download="John_Doe_CV.pdf"` attribute in `index.html` to match your name

## Image Guidelines:

- **Hero background**: Use high-quality images (at least 1920px wide)
- **File size**: Optimize images to keep file sizes reasonable (under 1MB for web)
- **Format**: JPG for photos, PNG for graphics with transparency
- **Content**: Choose professional images that represent your brand

## CV Guidelines:

- **File name**: Use a descriptive name like "YourName_CV.pdf"
- **File size**: Keep under 5MB for faster downloads
- **Content**: Ensure your CV is up-to-date and professionally formatted
